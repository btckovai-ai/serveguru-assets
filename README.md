# ServeGuru Global Media & Product Assets CDN

This repository hosts official media and product catalog assets for **ServeGuru** (Bharat Trading Corporation, Est. 1989).

Assets in this repository are served worldwide with sub-20ms edge latency via **jsDelivr** and **Cloudflare**:
- **CDN Base URL:** `https://cdn.jsdelivr.net/gh/btckovai-ai/serveguru-assets@main/`
- **Catalog Products:** `https://cdn.jsdelivr.net/gh/btckovai-ai/serveguru-assets@main/products/[filename]`
